# 追加変更 記録アプリ（PWA）

追加変更工事1件ごとに「写真（何枚でも・着手前/施工中/完了後）＋変更箇所・変更内容・作業内容・人数」を登録し、あとで選んだ工事をA4の記録用紙PDF（1ページに写真3枚）にして出力するスマホアプリです。

- 記録と写真は **利用者のスマホの中だけ** に保存されます（サーバーには送りません）。
- 利用は **承認制** です。使いたい人が申請 → 管理者がメールのボタンで承認／却下します。
- 1工事の写真が4枚以上のときは、自動で2ページ目以降に続きます（1ページに写真3枚。写真1枚ごとに、右にその工事の内容を印字）。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・PDF作成・承認の確認がすべて入っています） |
| `sw.js` | 電波がなくても開けるようにする仕組み |
| `manifest.webmanifest`, `icons/` | ホーム画面に追加したときの名前とアイコン |
| `gas/Code.gs` | 承認用のGoogle Apps Script（申請の受付・管理者へのメール・承認の確認） |

## 公開の手順（GitHub Pages）

1. GitHubに新しいリポジトリを作り、`index.html` `sw.js` `manifest.webmanifest` `icons/` を置く（`gas/` と `README.md` は置いても置かなくても可）。
2. リポジトリの Settings → Pages で、公開元を `main` ブランチ・`/ (root)` にする。
3. 表示されたURL（`https://〇〇.github.io/リポジトリ名/`）が、利用者に配るURLです。QRコードにして配ります。

## 承認の設定（Google Apps Script）

1. Googleスプレッドシートを新しく作る（名前は自由。例: 追加変更記録 利用者）。
2. メニュー「拡張機能」→「Apps Script」を開き、`gas/Code.gs` の中身を全部貼り付けて保存する。
3. 関数の選択欄で **`setup`** を選んで「実行」→ 権限の確認画面が出るので許可する（最初の1回だけ）。
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 表示された「ウェブアプリのURL」（`…/exec` で終わるもの）をコピーする。
6. `index.html` の先頭近くにある `APPROVAL_URL: ''` の `''` の中にそのURLを貼り付け、GitHubに上げ直す。

承認の流れ：利用者が氏名・会社名を入れて申請 → あなたのメールに「承認する／却下する」が届く → 押すと確認ページが開き、ボタンを押すと決定。スプレッドシートの「状態」欄（申請中／承認／却下）を直接変えても同じです。却下にすると、その人は次にオンラインで開いたときから使えなくなります。

> `APPROVAL_URL` が空のままだと、承認なしで誰でも使えます（試用用）。公開前に必ず設定してください。

## 利用者への案内

- 配られたURL（QR）をスマホで開く。
- iPhone: Safariの共有ボタン →「ホーム画面に追加」。Android: メニュー →「ホーム画面に追加」。
- **ホーム画面に追加しないと、iPhoneでは一定期間で記録が消えることがあります。**
- 初回に氏名・会社名を入れて申請し、承認を待つ。

## 更新するとき

- 内容を直したら、`sw.js` の `const CACHE = 'kiroku-v2'` の数字を上げてから公開してください（利用者のスマホが新しい版に替わります）。
- `Code.gs` を直したときは、Apps Scriptで「デプロイを管理」→ 編集 →「新バージョン」で再デプロイが必要です。

## 確認できていること／できていないこと

確認できている（パソコン上の自動テスト）
- 現場の追加 → 写真3枚の工事と5枚の工事を登録 → 全選択（写真8枚）でPDF3ページ（A4）、入力途中の工事は出力対象外
- 長い文章は文字を小さくして最後まで印字
- 承認の流れ（申請 → 承認待ち → 承認 → あとから却下でブロック）。Google側は模擬のサーバーで確認

**まだ確認できていない（要確認）**
- iPhone・Androidの実機での動作（カメラ起動、写真の向き、PDFの共有／保存、ホーム画面アプリでの動き）
- `Code.gs` を実際のGoogle上で動かしたときの動作（メール送信、承認ボタン、デプロイ設定）
- Googleのメール送信上限などの数値（公式情報で未確認）

## 既知の制限

- アプリを削除する、またはブラウザ/サイトのデータを消去すると記録も消えます（自動では消えにくい設計ですが保証ではありません）。
- 記録はスマホの中だけです。スマホの変更・故障・アプリの削除で消えます。提出用のPDFは必ず別に保存してください（バックアップ機能は未実装）。
- 撮影日時はスマホの時計を使います（時計を変えれば変わります）。Androidではアルバムの写真も選べる場合があります。
- 一度に出力できるのは10ページまでです。それ以上は分けて出力してください。
- 縦長の写真は、全体が見えるように左右に余白が入ります（切り取りません）。
- 保存年数・元請への提出ルールなど、書類の扱いは別途ご確認ください。
